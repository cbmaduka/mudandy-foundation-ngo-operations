# Workspace Setup

## Overview

To support Mudandy Foundation's growing portfolio of community programs, a dedicated workspace was created in Monday.com to centralize project planning, collaboration, and program monitoring.

The workspace serves as the organization's operational hub, allowing teams to manage initiatives from initial requests through planning, implementation, monitoring, and completion.

---

## Workspace Configuration

**Workspace Name**

```
Mudandy Foundation
```

**Primary Board**

```
Community Programs
```

The board was configured as the organization's central repository for tracking community initiatives across multiple program areas.

---

## Initial Board Structure

Five workflow groups were created to reflect the NGO's operational lifecycle:

- Program Requests
- Planning
- Active Programs
- Monitoring & Evaluation
- Completed Programs

This structure provides a clear progression for every initiative while enabling leadership to quickly identify the status of ongoing work.

---

## Board Purpose

The Community Programs board enables the Foundation to:

- Receive and organize new program requests
- Plan upcoming initiatives
- Track active community programs
- Monitor implementation progress
- Archive completed projects for reporting and institutional learning

---
## Consultant Notes

The workspace was intentionally designed around the Foundation's operational workflow rather than Monday.com's default templates. This approach ensures that programs follow a consistent lifecycle from intake through completion while providing leadership with a clear, portfolio-level view of organizational activities.
